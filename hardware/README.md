# Hardware sources

[Русская версия](README.ru.md) · [Back to the project overview](../README.md)

KiCad 10 project for the 0–50 V precision laboratory power supply. Open `POWER_0-50.kicad_pro`; the project-local footprint library resolves through `${KIPRJMOD}`, so no global library setup is needed.

> **Work in progress, published as-is.** The schematic and the layout are complete for this revision, but no board has been built or tested. Expect to find mistakes, and read [`docs/pcb.md`](../docs/pcb.md) before reusing anything — in particular the 0.6 mm pilot-hole convention, which will ruin a fab order if left as it is.

## Project footprint library

Everything that is either not in the stock libraries or had to be adapted for hand assembly:

- **Modules:** WeAct STM32G474CEU6 core board, Adafruit-style INA228 breakout (its screw terminal shares pad numbers with the header pins, so a wire can be soldered to whichever is convenient).
- **HSOP-8 with exposed pad, hand-solder pads:** `UCC27211` (EP → GND), `MP9486A` (EP → GND), `OPA454` (**EP → V− = −5 V**, not ground — see the datasheet).
- **Mechanical parts as real footprints:** three heatsinks, the constantan shunt staple, the flyback transformer on its measured bobbin, relays, the wound toroids, a THT NTC.
- Wide-pad SOIC-8/16 variants and various through-hole passives for parts that dissipate more than an SMD package can take.

## 3D models

KiCad 10 ships only STEP models, and several stock footprints in this project reference STEP files that are not in the distribution at all. The missing parts were modelled by hand as VRML and are generated by the scripts in `Library.3dshapes/_generators/`:

```
python wrlgen.py    # primitives, heatsinks, wound toroids, relays
python wrlgen2.py   # module boards, flyback transformer, NTC, SMD inductor
python wrlgen3.py   # fuse holder, connectors, shunt staple
python stand.py R21,J6   # preview rig: copies the board, keeps only the named parts
```

Two things worth knowing if you edit them: one VRML unit is 2.54 mm, the model Y axis is the negative of the board Y axis, and **KiCad's VRML loader does not draw the built-in `Cylinder` primitive at all** — every round shape here is an explicit `IndexedFaceSet` mesh.

## Netlist generator

The schematic was not drawn by hand first: `netlist/lab_psu_skidl.py` builds the circuit in SKiDL, and the resulting netlist is the reference that both the schematic and the board are verified against. If you change the circuit there, note that new parts must be appended at the **end** of the script — inserting them in the middle renumbers every later reference designator and silently desynchronises the board.
