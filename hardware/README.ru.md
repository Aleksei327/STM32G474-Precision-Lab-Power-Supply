# Исходники аппаратной части

[English version](README.md) · [К описанию проекта](../README.ru.md)

Проект KiCad 10 для прецизионного лабораторного блока питания 0–50 В. Открывать `POWER_0-50.kicad_pro`; библиотека посадочных мест проекта подключается через `${KIPRJMOD}`, глобальные настройки библиотек не нужны.

> **Работа в процессе, выложено как есть.** Схема и разводка для этой ревизии завершены, но ни одна плата ещё не собрана и не испытана. Ошибки возможны. Перед повторением прочитайте [`docs/pcb.ru.md`](../docs/pcb.ru.md) — особенно про пилотные отверстия 0,6 мм, из-за которых заказ на фабрике приедет непригодным.

| Путь | Что это |

| `netlist/lab_psu.net` | сгенерированный нетлист, эталон для сверки схемы и платы |
| `netlist/lab_psu_chips.kicad_sym` | символы деталей, которых нет в поставке KiCad |
| `jumper-wires.txt` | сборочный список 25 проволочных перемычек с координатами и длинами |

## Библиотека посадочных мест

Всё, чего нет в стоковых библиотеках либо что пришлось адаптировать под ручную сборку:

- **Модули:** плата WeAct STM32G474CEU6, модуль INA228 в стиле Adafruit (его клеммнику даны те же номера падов, что и контактам гребёнки, — провод можно паять туда, куда удобнее).
- **HSOP-8 с теплоотводящей площадкой, пятаки под ручную пайку:** `UCC27211` (EP → GND), `MP9486A` (EP → GND), `OPA454` (**EP → V− = −5 В**, а не земля — см. даташит).
- **Механика как настоящие посадочные места:** три радиатора, константановая скоба-шунт, флайбэк-трансформатор по фактическим замерам каркаса, реле, намотанные тороиды, выводной NTC.
- Варианты SOIC-8/16 с расширенными пятаками и выводные пассивные детали там, где мощность не влезает в SMD-корпус.

## 3D-модели

KiCad 10 поставляется только со STEP-моделями, а несколько стоковых посадочных мест в этом проекте ссылаются на STEP-файлы, которых в поставке вообще нет. Недостающие детали нарисованы вручную в VRML и генерируются скриптами из `Library.3dshapes/_generators/`:

```
python wrlgen.py    # примитивы, радиаторы, намотанные тороиды, реле
python wrlgen2.py   # платы-модули, флайбэк-трансформатор, NTC, SMD-дроссель
python wrlgen3.py   # держатель предохранителя, разъёмы, скоба шунта
python stand.py R21,J6   # стенд для осмотра: копия платы только с указанными деталями
```

Два нюанса, если будете править: одна единица VRML — это 2,54 мм, ось Y модели противоположна оси Y платы, и **встроенный примитив `Cylinder` KiCad не рисует вообще** — все круглые формы здесь собраны явной сеткой `IndexedFaceSet`.

## Генератор нетлиста

Схема не рисовалась вручную с нуля: `netlist/lab_psu_skidl.py` описывает схему на SKiDL, и полученный нетлист служит эталоном, по которому сверяются и схема, и плата. Если правите схему там, помните: новые детали добавлять **в самый конец** скрипта — вставка в середину сдвигает позиционные обозначения всех последующих деталей и незаметно рассинхронизирует плату.
